Clip Path and Mask Image

Both properties hide parts of an element, but they do it in different ways. Clip paths create hard geometric edges, while masks create soft transparency.

Click each button to change the visible shape of the same image.

Demo 3

Gradient Mask Fade

When to Use Which

Use clip-path when...

You need hard geometric shapes, angled sections, circles, diamonds, or polygon-based hover effects.

Use mask-image when...

You need soft fades, gradual transparency, vignettes, or image-based reveal effects.
